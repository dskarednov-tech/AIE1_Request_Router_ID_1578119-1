# Маршрутизатор обращений службы поддержки (Baseline)

## Назначение программы
Программа служит базовым решением (baseline) для автоматической классификации и приоритизации входящих обращений пользователей службы поддержки по явным правилам.

## Требования к окружению
- **Python:** версия 3.14.7 (`python --version`)


## Поддерживаемые форматы входных данных
- **JSON** (`.json`) — массив объектов с полями `id` и `text`.
- **CSV** (`.csv`) — табличные данные с заголовками `id,text`.

## Поля результата обработки
Для каждого обращения формируется объект со следующими полями:
- `id` — идентификатор обращения (строка).
- `category` — определенная категория обращения (`access`, `billing`, `bug`, `other` и т.д.).
- `priority` — уровень приоритета (`high`, `medium`, `low`).

## Запуск из терминала

Команды нужно выполнять из корня проекта.

### Справка

```bash
python src/main.py --help
```

### Обработка JSON

```bash
python src/main.py --input datasets/requests.json --output src/result.json
```

Результат будет сохранен в `src/result.json`.

### Обработка CSV

```bash
python src/main.py --input datasets/requests.csv --output src/result.json
```

Результат будет сохранен в `src/result.json`.

### Проверка кода завершения

После выполнения команды в Git Bash можно проверить код завершения:

```bash
echo $?
```

Код `0` означает успешное выполнение. Код `1` означает ошибку входного файла или данных.

## Дополнительная функция

После успешной обработки программа выводит в терминал количество обращений
по категориям: `access`, `billing`, `bug` и `other`.

Статистика не изменяет формат JSON-файла результата.
